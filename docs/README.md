## Соглашения

- **Проект** обозначается `slug` (`todo-bot`), задача — ключом (`T12` из плана, `A3` для разовых задач вне плана), веха — `M1`.
- Все даты и время — в часовом поясе из настройки `timezone`.
- Флаги и форматы CLI агентов сверены с Claude Code 2.1 и codex-cli 0.160–0.162; при обновлении CLI — см. [development.md](development.md#грабли-проверенные-на-практике).
